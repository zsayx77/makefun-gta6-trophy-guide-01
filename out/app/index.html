      How this guide was made

      Every trophy's name, description and grade is shown exactly as PlayStation publishes it, as listed by Exophase and PSNProfiles before this guide was written. Every guide is written in this guide's own words. Where a guide gives a specific location or step, it says where the fact comes from; where no source publishes the detail — for example the number of meditation spots, or what exactly triggers “Personal Best” — the guide says so instead of inventing one. A cited guide beats an uncited one, however detailed.

      How to use the tracker

      • Tick a trophy when you earn it. Ticks are saved in this browser (localStorage) and survive reloads.
      • Export progress downloads a small JSON file; Import progress loads one back. Keep the export as a backup before clearing browser data.
      • Hide story spoilers replaces the names and descriptions of story trophies you have not earned yet with a hidden placeholder. Earned trophies always show.
      • Missable flags the three trophies tied to a one-time moment: two story choices and one stealth attempt. Save before story choices.

      Offline

      This guide is plain static files. It loads nothing from the network, uses no external fonts or images, and works with the network off.
