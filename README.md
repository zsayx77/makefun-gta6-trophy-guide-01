Leonida Trophy Guide — an offline guide and tracker for all 55 GTA 6 trophies on PlayStation 5: cited guides, a roadmap to the platinum, missable flags, and a checklist with filters, spoiler mode, and export/import. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide works offline, with no network request.
